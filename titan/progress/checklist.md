# 검수 체크리스트 (리스트업 초안)

2026-10-16 / 설계단계 / 검수 양식(docx)의 검사항목·검사내용·검사기준에 넣을 후보 목록. 외부 연동·품질/성능 중심, UI·기능은 필수만.

- 읽는 사람 = 검수자·발주처. 내부 구현·버그 이력은 쓰지 않고 **"무엇을 해 보면 되는가 / 무엇이 나오면 합격인가"**만 적는다.
- 표 구성: **검사항목**(대분류) / **검사내용**(중분류) / **검사기준**(세부) / **📷 사진**(넣으면 좋은 스크린샷).
- **대분류 5개**: 가상환경·모델링 / 외부 연동 / 자체 동작 기능 / UI / 품질·성능.
- **중복 방지 원칙: 기능 하나는 한 곳에만 둔다.**
  - **외부 연동(2장)** = 외부 장비가 시키거나 외부로 내보내는 것. **연결 상대별**로 나눈다(통제기 / 영상 / 조작 장치 / 시뮬레이터 간 / 상위체계). 명령을 보내고 동작까지 확인하는 것도 여기서 한 행으로 끝낸다.
  - **자체 동작 기능(3장)** = 외부 명령 없이 시뮬레이터가 스스로 하는 것(자율주행, 드론 자동 비행, 사격 효과, 시나리오 진행 등).
- `[협의]` = 합격 기준 수치를 정해야 하는 항목. `[제외]` = 상위체계 미확정이라 이번 검수 대상이 아닌 항목.
- 📷 칸: 비어 있으면 사진 불필요(동작·수치로 확인하는 항목). `★` = 붙임 사진에 꼭 넣을 대표 컷.

| | RCWS 사격 절차 | 안전/사격 활성 → 장전 → 발사 순서·조건을 지켜야만 사격됨. 단발/점사/연사 모드대로 발수가 나감 | 통제기 조작 → 시뮬레이터 사격 화면 |

| | 위치·방위 | 위치(군용 격자 좌표)·속도·방위가 주기적으로 송신되고 미니맵 위치와 일치 | 통제기 지도 위치 vs 시뮬레이터 미니맵 |
| | 탐지 결과 | 아군 · 적군 · UGV · 이동지휘소 · 드론 · 낙하산 6종이 구분되어 탐지되고, 분류·화면 위치·좌표·속도가 주기적으로 송신되어 화면 표식과 일치 | ★ 통제기 탐지 목록 vs 시뮬레이터 표식 (가능하면 6종 각각) |

## 3. 자체 동작 기능

외부 명령 없이 시뮬레이터가 스스로 하는 것만.

| 검사항목 | 검사내용 | 검사기준 | 📷 사진 |
|---|---|---|---|
| UGV 자율 주행 | 경로 주행 | 목적지를 주면 경로를 따라 주행해 도착 반경 안에서 정지함 | |
| | 험지·장애물 | 경사·나무 지대를 주행 중 걸리거나 전복되지 않음 | 숲·경사 주행 컷 |
| 드론 자동 비행 | 이륙·이동·호버링 | 이륙 후 지정 지점으로 이동하고 도착 후 제자리 비행 유지 | ★ 비행 중인 드론 외부 시점 |
| | 전장 자동 관측 비행 | 교전이 시작되면 드론이 비행 경로 위에서 전장이 가장 잘 보이는 지점으로 스스로 이동함 | ★ 드론 화면에 교전 장면이 잡힌 컷 |
| | 짐벌 자동 추적 | 짐벌 카메라가 교전 중인 분대를 자동으로 따라가 화면 안에 유지함 | |
| | 짐벌 수평 유지 | 기체가 기울어도 카메라 화면 수평이 유지됨 | |
| RCWS | 거리 측정 | 표적까지의 거리가 측정·표시됨 | 거리값 표시 컷 |
| | 사격 효과 | 총구 화염·탄피·궤적·피격 효과·사격음이 사격과 함께 나옴 | ★ 사격 순간(화염·궤적·피격) |
| 시나리오 | 전체 흐름 | 시작 → 적 출현 → 드론 이동·식별 → UGV 출동 → 교전 → 적 도주/섬멸 → 종료까지 끊김 없이 진행 | ★ 단계별 대표 컷(낙하산 식별 / UGV 출동 / 교전 / 종료) |

| | 재시작 | 재시작 시 모든 상태(차량 위치·병사·드론 표시값)가 초기 상태로 돌아감 | 재시작 확인창 |
