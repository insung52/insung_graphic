# 검수 체크리스트 (리스트업 초안)

2026-10-16 / 설계단계 / 검수 양식(docx)의 검사항목·검사내용·검사기준에 넣을 후보 목록. 외부 연동·품질/성능 중심, UI·기능은 필수만.

- 읽는 사람 = 검수자·발주처. 내부 구현·버그 이력은 쓰지 않고 **"무엇을 해 보면 되는가 / 무엇이 나오면 합격인가"**만 적는다.
- 표 구성: **검사항목**(대분류) / **검사내용**(중분류) / **검사기준**(세부) / **📷 사진**(넣으면 좋은 스크린샷).
- 중복 정리 원칙: 같은 기능이라도 **시뮬레이터 안에서 그 동작이 맞게 일어나는가**는 2장(기능)에, **통제기에서 보낸 명령이 통신으로 들어와 반영되는가**는 3장(외부 연동)에 둔다. 3장은 명령 하나하나가 아니라 명령 묶음 단위로 묶는다.
- `[협의]` = 합격 기준 수치를 발주처와 정해야 하는 항목. `[제외]` = 상위체계 미확정이라 이번 검수 대상이 아닌 항목.
- 📷 칸: 비어 있으면 사진 불필요(동작·수치로 확인하는 항목). `★` = 붙임 사진에 꼭 넣을 대표 컷.

### 메모 (검수 전 정해야 할 것)
