  • 조준·총내림·기울이기·맹목사격·앉기 같은 자세는 이동 클립 위에 얹힙니다. 얹히는 재료 중 파일인 것(고칠 수 있음)과 코드가 본을 직접 움직이는 것(고쳐도 안 바뀜)을 2절·3절에서 기능마다 나눠 적었습니다.
  • 모든 클립은 /Game/SoldierLab/Animations/ 아래, 스켈레톤은 SK_UEFN_Mannequin입니다. 이름·경로를 바꾸지 말고 리임포트로 덮어써 주세요.
  • 테스트는 /Game/SoldierLab/Levels/L_SoldierTest 레벨에서 합니다 (→ 1절).

3. 파일을 고쳐도 안 바뀌는 것 — 코드가 본을 직접 움직이는 층

이것들은 애니메이션 파일 위에 항상 얹힙니다. 문제가 여기서 보이면 저희에게 알려 주세요.

#무엇어떻게언제 0이 되나
①좌우 기울이기척추 5마디 회전기울이기 키를 안 누를 때
②서기 ↔ 앉기 중간 높이골반을 내리고 무릎을 굽힘완전히 섰을 때 / 완전히 앉았을 때
③조준 방향 적용2.3의 포즈를 조준 각도만큼 섞음정면·수평 조준
④총구 보정총구가 조준선에서 벗어난 만큼(±25° 이내) 조준 각도를 되먹임2.3 포즈가 정확할수록
⑤총내림 합성2.4의 델타를 마스크로 얹음견착 중
⑥맹목사격 적용2.5의 포즈를 상체 마스크로 얹음맹목사격 키를 안 누를 때
⑦발 접지 · 보폭/방향 워핑 · 몸통 지연기본 제공 기능. 클립 속도와 실제 속도의 차이를 다리 변형으로 흡수클립 속도 = 코드 속도일 때 최소
검수 요령 — 파일이 그대로 보이는 조건은 제자리 · 정면 조준(또는 총내림 정지) · 축 전부 0입니다. 그 상태에서 먼저 보고, 키를 하나씩 눌러 가며 ①~⑥이 얹힌 모습을 따로 봐 주세요.

4. 수정 규칙

  1. 이름·경로·파일을 바꾸지 않습니다. 리임포트로 덮어씁니다. 새 파일을 만들면 어디에도 안 걸립니다.
  2. 루프 클립은 첫·끝 프레임이 이어져야 합니다. 루트 본은 잠급니다(Force Root Lock 켜짐 유지).
  3. 고치거나 새로 만든 클립은 목록으로 알려 주세요. 각 클립에는 발 접지·워핑 같은 보조 데이터(커브)가 붙어 있는데, 포즈가 바뀌면 다시 계산해야 하고 새 클립에는 아예 없습니다. 이 작업은 저희가 합니다 — 파일만 넣어 주시고 어떤 클립인지 말씀해 주시면 됩니다. (안 하면 발이 조용히 미끄러집니다.)
  4. 2.3 · 2.4 · 2.5의 기준 프레임 0 종속을 기억해 주세요 — 기준을 고치면 딸린 포즈를 같이 확인합니다.
  5. 1프레임 포즈(2.3 · 2.4 델타 · 2.5)는 프레임 0에만 키를 찍습니다.
  6. 이동 클립을 추가·삭제하거나 속도를 바꿀 땐 먼저 말씀해 주세요.
  7. 스켈레톤(SK_UEFN_Mannequin)에 본을 추가하지 않습니다.

4.1 아군/적군 외형으로 작업하기

  • 애니메이션 파일의 프리뷰 메시가 지금은 전부 마네킹인데, 이건 에디터 표시용일 뿐 게임에 영향이 없습니다. 아군(soldier_T)·적군(new_enemy_T) 메시가 같은 스켈레톤을 쓰므로 애니메이션 에디터의 Preview Scene Settings → Preview Mesh에서 바꿔 놓고 보셔도 됩니다.
  • FBX로 내보내 외부 툴에서 작업하실 때도 마찬가지입니다 — 내보낼 때 Export Preview Mesh를 켜면 아군/적군 몸이 같이 나가고, 다시 들여올 땐 원래 파일에 Reimport(스켈레톤 SK_UEFN_Mannequin 유지)로 덮어쓰면 됩니다. 본 이름·계층을 바꾸지 않는 것만 지켜 주세요.
  • 아군과 적군은 마네킹보다 키가 크고 비율이 조금 다릅니다. 두 외형에서 다르게 보이는 부분이 있으면 알려 주세요 — 어느 쪽 기준으로 맞출지 같이 정하겠습니다.
