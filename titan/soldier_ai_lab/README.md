## 무엇을 만드는가

병사 하나하나가 **주변 환경·적 위치·아군 위치를 실시간으로 스스로 판단**해서 엄폐 위치를 고르고,
사격 타이밍을 정하고, 분대와 협동하는 시스템. 발걸음·총구 방향·손 동작·장애물 상호작용까지
사실적으로.

**최종 통합 그림**: `titan_example`의 시나리오 시스템이 상부 지휘부처럼 **"저 목표 교전 개시",
"2차 전투지로 이동"** 같은 고수준 명령만 내리고, 병사 개개인이 그것을 자기 판단으로 해석해서
행동한다. 지금처럼 시나리오가 병사의 세부 행동까지 직접 트리거하는 방식이 아니라, **명령↔실행
사이에 진짜 "판단" 레이어**가 있는 구조.

**목표 규모**: 45명(아군 30 + 적군 15) @ 60fps — `titan_example` 현행 규모와 동일.

## 핵심 결정 요약

| 영역 | 결정 | 왜 |
|---|---|---|
| 스켈레톤 | **UE5 Mannequin 전면 교체** | 현행 Mixamo 리그에 Root 본이 없어 Motion Matching이 원천 불가 |
| 베이스 | **GASP(Game Animation Sample) 복제 후 확장** | 삽입 지점이 이미 설계돼 있고, 품질 재현 비용이 크다 |
| 로코모션 | **풀바디 Motion Matching** | 실제 속도로 포즈를 고르므로 속도↔애니메이션 배관이 사라진다 |
| 조준 자세 | **풀바디 베이스 + 절차적 워핑 + 애디티브** | 상하체 레이어 분리는 이 프로젝트가 이미 실패로 확인 |
| 판단 | **유틸리티(판단) + StateTree(실행) 2계층** | 판단과 실행은 성질이 다르다. 합치면 우선순위가 트리에 하드코딩된다. ⚠ **2026-09-13 현재 이 형태로 만들어지지 않았다** — 판단은 StateTree가 아니라 컴포넌트 + Tick 접합이 한다 |
| 자산 | **유료 배제 · 무료 클립 + 루트모션 합성** | 디자인팀이 0부터 제작 불가 |
| 사격 | **히트스캔이 아니라 탄도 투사체** | 리드 사격·탄착 낙차·비행 시간이 있어야 교전이 읽히고, 그 셋이 AI가 쓸 재료다 |
| 인지 | **신선도와 해상도를 분리해 들고, 감쇠는 질의 시점에** | 총성은 확신은 높고 위치는 쓸모없다 — 합치면 서로를 지운다. 관측을 그대로 두면 **늦게 온 무전이 공짜로 제 나이만큼 낡는다** |
| 정보 융합 | **역분산 가중(칼만 갱신)** | "목격이 총성을 이긴다" 같은 **우선순위 규칙이 통째로 사라진다** |
| 사격 판단 | **"맞출 수 있나"가 아니라 "내 앎이 내 무기보다 나쁜가"** | 3° 산포에서 40m 표적은 2%다 — 명중확률 게이트는 뜻이 없다. 바꾼 질문은 **양변이 이미 있는 물리량**이라 튜닝 문턱이 없다 |
| 목표 | **로직 없는 레벨 마커 하나가 양쪽을 섬긴다** — 쥔 쪽은 지키고 나머지 전부가 뺏는다. 수비 비용은 반경 안이 **평평한 0** | 마커를 둘 놓으면 **어긋나게 놓을 수 있다.** 그리고 거리로 매기면 **수비대가 중심점으로 붕괴한다** — 지킬 것이 구역이면 비용도 구역이어야 한다 |
| 위치 선택 | ~~도착지 **노출**~~ → **싸울 수 있는 자리**(`FightingCost`) + 경로 노출 + 땅의 값 | 항이 하나뿐인 최적화기에서 **빠진 항은 거동으로 드러난다**(= 무모함). 그리고 노출만 최소화하면 **깊은 구석이 만점**인데 거기 있는 병사는 **맞을 수도 쏸 수도 없다** — **완벽한 엄폐와 사격 위치는 반대말**이다. **측면기동은 정면이 비싸질 때 남는 것** |
| 엄폐 | ~~Smart Object 예약 + EQS 스코어링~~ → **시야 판정을 거꾸로 돌린다** | 볼륨도 마커도 베이크도 없다. **벽을 옮긴 디자이너가 엄폐를 옮긴 것**이다. (예약 문제는 분대 층에서 다시 만난다) |
| 노출 | **사다리다** — 막힌 사선에는 **조리개**(위/옆)를 찾고, 몸을 얼마나 내보낼지를 **제압도**로 고른다 | 물체를 지나가는 방법이 **위와 옆뿐**이라, 그 둘이 포즈 파이프라인이 이미 갖고 있던 두 축과 그대로 같았다. 맹목사격의 큰 벌점은 밸런스 다이얼이 아니라 **절대 가치 게이트가 먼 맹목사격을 거절하게 만드는 장치** |
| 거동 | **규칙이 아니라 선호로 쓴다** — "X면 Y하라"는 금지 | 규칙은 **아무도 예상하지 못한 상황이 오는 순간 틀린다.** 스프린트는 "위험하면 달려라"가 아니라 **느릴 이유의 부재**다 |
| 협업 | **P0 검증 후 비교 영상과 함께 공유** | 근거는 있으나 시연이 없다 |
