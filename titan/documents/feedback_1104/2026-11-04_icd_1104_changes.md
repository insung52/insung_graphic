## 2. 수정 필요 — 시트 2 (UGV → LIG)

### 2-1. 키 오타 정정 (확정)

| 위치 | 기존 | 변경 | 코드 위치 |
|---|---|---|---|
| `UGV_Period_Basicinfo` | `ConrtrolRight` | `ControlRight` | `UGVRemoteControlSubsystem.cpp:833` |
| `UGV_Period_Basicinfo` | `Batterry` | `Battery` | `UGVRemoteControlSubsystem.cpp:836` |
| `UGV_Period_ObjectDetectionResult` (RCWS) | `Latter` | `Letter` | `UGVRemoteControlSubsystem.cpp:107~128` (`bUseLatterTypo` 분기) |

- 사용자 메모: "keys 부분 오타 **몇 개** 존재" — 위 3건이 diff로 확인된 전부. 그 외 오타가 있다면 LIG 확인 필요.
- 코드에 이미 `bUseLatterTypo` 스위치가 있어 `Letter`로 통일하면 분기 정리 가능(ADU 쪽은 원래 `Letter`).

### 2-2. 필드 추가 — `UGV_RCWS_Status` (20Hz)

| 키 | 설명 | 타입 | 범위 | 현재 |
|---|---|---|---|---|
| `Azimuth` | 방위각 | int | 0~360 | 미송신 |
| `Elevation` | 고각 | int | 0~180 ("-90로 보정해서 사용예정") | 미송신 |
| `TotalBullet` | 전체 탄알수 | int | MAX 200발 | 미송신 |

- 현재 `SendRCWSStatus()`(`:840`)는 `RCWSStatus`(ON/OFF)만 보냄.
- **불명확**(LIG 확인): `Azimuth` 기준(차체 상대/진북 절대), `Elevation`에 어떤 값을 넣으면 "−90 보정"이 맞는지(90=수평?), `TotalBullet`이 잔탄인지 최대 탄수인지.
- 내부 데이터: RCWS 마운트 yaw/pitch, 탄약(`AmmoMax`/현재 잔탄)은 `URCWSComponent`에 있음.
- 우리 RCWS 앙각 범위는 -20°~60° → "0~180, −90 보정" 규칙에 넣으면 70~150(= 앙각+90)으로 나올 것. 확정 전 임시안.

### 2-3. 필드 추가 — `Runtime`

| 키 | 위치(메시지) | 설명 | 타입 | 형식 |
|---|---|---|---|---|
| `Runtime` | `UGV_Period_BasicInformation` (UGV_ADU) | 총 실행시간 (UGV 에뮬레이터 구동시간) | String | `HH-MM-SS` |

- 현재 `SendBasicInformation`(`:926`)에는 `Odometer`만 있음.
- 형식이 `HH-MM-SS`(하이픈)로 적혀 있음 — 콜론이 아님. 원문 그대로 따를지 LIG 확인.
- **시나리오 재시작 시 0으로 초기화할지** 미정(사용자 질문) → LIG 확인. 초기화한다면 재시작 훅(`IScenarioResettable`/상태 컴포넌트)에 접점 추가.

### 2-4. 피드백 — `UGV_Period_ObjectDetectionResult` (객체 인식 결과)

- LIG 피드백: **"영상의 보이는 타겟의 위치와 box의 위치 차이가 심함"** (필드 변경 아님, 동작 버그 의심).
- 우리 테스트(`ugv controller demo`)에서는 심하지 않았다는 사용자 메모 → LIG 환경과의 차이를 좁혀야 함.
- 박스 좌표: `LeftTopX/Y`, `RightBottomX/Y` = 픽셀 × 65535 / 영상 가로·세로 (65535 스케일).
- 조사 후보: ① 캡처 해상도 vs 박스 계산에 쓰는 해상도 불일치 ② RTSP 인코드·전송 지연으로 영상이 늦음(박스는 현재 위치) ③ 줌/FOV 반영 누락 ④ EO/IR 모드별 FOV 차이 ⑤ LIG가 환산에 쓰는 해상도 가정이 다름.
- `ObjectClass`는 ICD에 `Human : 사람 / Car : 차량`뿐 — 우리는 6분류 확장 송신 중 (`protocol/2026-09-02_object_class_expansion.md`). 아래 3번 메모와 연관.

## 3. 수정 필요 — 시트 3 (LIG → UGV)

| 위치 | 변경 | 내용 |
|---|---|---|
| `RC_RemoteDriving.Steering` | 피드백 추가 | **"좌/우 조향 감도 낮추는 걸로 조정 필요"** |
| `RC_SelectCamera.SelectCameraButton` | (사용자 메모) | "IR 카메라 흑백 마스킹" — **셀 값에는 안 보임**(셀 메모일 수 있음). 시트 3 셀에서는 피드백 열이 빈 값 |
| `ObjectClass` (시트 2·3) | (사용자 메모) | "값을 기존 claaified" — 셀 값은 둘 다 `Human`/`Car`로 변경 없음 |

- `Steering` 처리 위치: `UGVRemoteControlSubsystem.cpp:479~488` (`TurnInput = Clamp(Steering,-100,100)/100`).
  감도를 낮추는 방법 후보: 비선형 곡선(작은 입력 둔감), 상한 스케일(예: 0.6), 속도 의존 감쇠. 정량 기준 LIG 확인 필요.
- `SelectCameraButton` IR "흑백": 현재 IR은 초록(나이트비전식) 후처리. 흑백으로 바꾸라는 뜻인지 LIG 확인 후 후처리 머티리얼 수정.
